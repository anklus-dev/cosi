# Functions and Mappings

A function f from set A to set B assigns exactly one element of B to every
element of A. We write this as f colon A arrow B. The set A is called the
domain, and B is called the codomain of the function.

A function is injective, or one-to-one, if different inputs always produce
different outputs. Formally, if f of x equals f of y, then x must equal y.
No two distinct domain elements are ever mapped to the same output value.

A function is surjective, or onto, if every element of the codomain is hit
by at least one element from the domain. In other words, the range of the
function equals the entire codomain, with nothing left uncovered.

A function that is both injective and surjective is called bijective. Bijective
functions have a very useful property: they are invertible, meaning there
exists an inverse function that perfectly undoes the original mapping.
