# Relations and Equivalence Classes

A relation R on a set A is a subset of the Cartesian product A times A. In plain
terms, a relation just describes which pairs of elements are connected to each
other according to some rule, like "is greater than" or "is a friend of."

A relation is reflexive if every element relates to itself, meaning x R x holds
for all x in the set. It is symmetric if whenever x R y holds, y R x also holds.
It is transitive if x R y and y R z together imply that x R z must also hold.

When a relation is reflexive, symmetric, and transitive all at once, it is called
an equivalence relation. Equivalence relations partition a set into disjoint
groups called equivalence classes, where every element in a class is related to
every other element in that same class.

Not every relation is transitive. A good example is "is a friend of" on social
media: your friend's friend is not automatically your friend. This kind of
non-transitive relation shows up constantly outside of pure mathematics.
