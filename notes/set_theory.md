# Set Theory Basics

A set is an unordered collection of distinct objects, called elements or members.
We write x in A to mean x is an element of set A. Two sets are equal if and only
if they contain exactly the same elements, regardless of order or repetition.

The union of two sets A and B, written A union B, is the set of all elements that
are in A, in B, or in both. The intersection, written A intersect B, is the set of
elements that are in both A and B at the same time. If two sets share no elements
at all, they are called disjoint sets.

A subset relationship holds when every element of set A is also an element of set B.
We write this as A subset B. The empty set, containing no elements at all, is a
subset of every possible set, including itself.

Power sets are the set of all possible subsets of a given set, including the empty
set and the set itself. If a set has n elements, its power set has exactly two to
the power of n elements, which grows extremely fast as n increases.
